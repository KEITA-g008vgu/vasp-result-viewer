VASP Result Viewer  v2.6.8  取扱説明書
======================================================================
VASP 6.6 の計算結果を可視化する Windows 用アプリです。
VASP Input Generator（INCAR / KPOINTS 作成アプリ）とは別のアプリで、
描画の設定と画面まわり（高 DPI 対応、スクロールできるメニュー、OpenGL 3.3 描画、
VESTA の色・原子半径・結合、マウス操作）は VASP Input Generator v1.8.8 と同じです。

  ソース      : vasp_viewer.py（1 本）
  exe の作成  : build_exe.bat を実行 → dist\VASPResultViewer.exe
  この説明書  : 取扱説明書_VASPResultViewer.txt


1. 起動と読み込み
----------------------------------------------------------------------
タブが 6 つあります（電荷密度・DOS / BAND・フェルミ面・輸送特性・結晶構造・ブリルアンゾーン）。各タブの「開く」ボタン、またはウィンドウへのドラッグ＆ドロップで
読み込みます。ドロップしたものの種類で、開くタブが自動で決まります。

  CHGCAR                      → 電荷密度
  vasprun.xml                 → DOS / BAND（line-mode なら BAND、それ以外は DOS）
  計算フォルダ                → 開いているタブで使えるファイルがあればそのタブ。
                                なければ EIGENVAL のあるフォルダはフェルミ面
  EIGENVAL / PROCAR / DOSCAR  → そのフォルダをフェルミ面として読む
  vaspout.h5                  → 輸送特性
  POSCAR / CONTCAR / *.vasp   → 結晶構造（ブリルアンゾーンタブにも入ります）
  POSCAR / CONTCAR だけのフォルダ → 結晶構造
  ※ どのタブでデータを開いても、その構造が結晶構造・ブリルアンゾーンタブに自動で入ります

※ 管理者として起動すると、Windows の仕様でドラッグ＆ドロップが届きません。

共通の操作（3D 表示）
  左ドラッグ: 回転 / 右ドラッグ: 移動 / ホイール: 拡大縮小
  メニューは境界線のドラッグで幅を変更、左端の ◀ / ▶ で表示・非表示。
  メニューが画面に収まらないときは縦スクロール（ホイール、タッチパッド 2 本指）。


キャッシュとライブラリ（ウィンドウ上部のボタン）
  キャッシュ（自動）
  ・一度読んだファイル（CHGCAR、vasprun.xml、フェルミ面のフォルダ、PROCAR）の中身を、数値のまま
    アプリの保存フォルダに自動で保存します。同じファイル（大きさと更新日時が同じ）を次に開くときは、
    それを読むので速くなります。元のファイルを計算し直した場合は、自動で読み直します。
  ・キャッシュは上限（既定 20 GB）を超えると、最後に使ったのが古いものから消えます。
    上限の変更と「キャッシュを空にする」は「ライブラリ…」の画面からできます。
  ライブラリ（名前を付けて保存）
  ・「表示中の内容をライブラリに保存…」で、開いているタブの内容に名前を付けて保存します。
    電荷密度（WAVECAR の軌道分解の結果を含む）・DOS / BAND（PDOS / PBAND のデータを含む）・
    フェルミ面（PROCAR の重みを含む）・輸送特性 のどれでも保存できます。
  ・「ライブラリ…」で一覧を開き、ダブルクリック（または「開く」）で開きます。元のファイルがなくても開けます。
    名前の変更・削除ができます。削除しても元の計算ファイルは消えません。
  ・WAVECAR の軌道分解の結果は、軌道・元素・原子の切り替えまでできます。別のバンドで計算し直すには
    元の WAVECAR のあるフォルダを開いてください。
  ・保存先: Windows では %LOCALAPPDATA%\VASPResultViewer（cache と library の 2 つのフォルダ）。
    環境変数 VASP_VIEWER_DATA で変えられます。
  ・保存した内容は保存した時点のものです。元の計算をやり直したら、読み込み直して保存し直してください。

表示の状態の復元（ウィンドウ上部の「前回の表示の状態を復元する」）
  ・同じデータ（同じファイル・フォルダ、またはライブラリの同じ項目）を次に開くと、前回の表示の状態に戻します。
    戻すもの: 視点（回転・拡大・移動）、等値面のレベル・不透明度・スーパーセル・ラベル・結合の設定（電荷密度）、
    E_F・エネルギー範囲・PDOS/PBAND・元素のチェック（DOS/BAND）、E_F・シフト・色の種類・元素/原子/軌道の
    チェック・色の範囲・しきい値・バンドのチェック・補間（フェルミ面）、表示する量・方向・温度など（輸送特性）。
  ・状態は、別のデータを開いたときとアプリを閉じたときに覚えます（アプリの保存フォルダの views.json）。
    ライブラリに保存するときは、そのときの表示の状態も一緒に保存します。
  ・チェックを外すと、復元せずに初期の表示で開きます。

最近開いたもの・設定の記憶
  ・ウィンドウ上部の「最近開いたもの ▾」に、最近開いたファイル・フォルダ・ライブラリの項目（最大 20 件）が出ます。
    選ぶとそのまま開きます。見つからないものは一覧から消えます。
  ・ウィンドウの大きさと位置、最後に開いたフォルダ（ファイルを選ぶ画面の最初の場所）を次回に持ち越します。
  ・データによらない表示の設定も次回に持ち越します: 不透明度・原子/結合/単位胞/軸の表示・ラベルの大きさ（電荷密度）、
    表示の切り替え・エネルギー範囲・ファットバンドの太さ（DOS/BAND）、BZ の表示・線・カラーバー・軸・背景色・
    しきい値（フェルミ面）、方向・表示する量・軸（輸送特性）。
  ・これらは、アプリを閉じるとき（ウィンドウの × ボタン）に保存します（ui.json）。

PROCAR の読み方（フェルミ面）
  ・最初に E_F 付近のバンドだけを、ファイルの位置を計算して読みます（読む量が少ないので早く色を付けられる）。
    続けて残りのバンドを裏で読み、読み終わったらキャッシュに保存します。
  ・E_F のシフトを大きく変えたときや、全バンドの frmsf を保存するときは、必要なバンドを読み終わるまで待ちます。

2. 電荷密度タブ
----------------------------------------------------------------------
読むファイル : CHGCAR（CHG, PARCHG も同じ形式なので読めます）
計算側の設定 : LCHARG = .TRUE.（SCF）

・ρ(r) の 3D 等値面を、原子・結合・単位胞と重ねて表示します。
・値は ρ(r) [e/Å^3] です（CHGCAR の値 ÷ セルの体積）。e/bohr^3 に換算した値も表示します。
・等値面レベルの初期値は VESTA と同じ式  d = <|ρ|> + 2σ(|ρ|)  です。
  描画領域の上の「等値面のレベル」の欄に数値を入れて、Enter か「反映」で変更します。「既定値」で初期値に戻ります。
・不透明度 0–1（1 で不透明）。等値面の色は VESTA の既定（正: 黄、負: 水色）。
・解像度「自動」は 1 辺が 160 点以下になるよう格子を間引きます。「全点」で間引きなし。
・SOC（非共線）やスピン分極の CHGCAR は、最初のブロック（全電荷）だけを読みます。
・スーパーセル: a, b, c の繰り返し数を入れて「更新」。原子・結合・等値面を並べて表示します
  （枠線は単位胞のみ。VASP Input Generator の結晶構造表示と同じ）。
  等値面の三角形が 400 万枚を超える場合は、等値面だけ最初の 1 セルに描きます。
・ラベル表示: チェックした元素の原子に、サイトの名前（A1, B3, …）を表示します。
  「全部」「なし」、文字サイズ [pt] を指定できます。隠れた原子のラベルは表示されません。
・描画領域の上（VESTA と同じ配置）: 1 行目に視点ボタン a, b, c, a*, b*, c*, 斜め, 全体表示, 初期位置 と
  「画像を保存…」（PNG）、2 行目に等値面のレベル。

描画方式（v2.6.0。左のメニューの一番下）
  ・GPU レイキャスティング（既定）: 三角形を作らず、画面の点ごとに視線をたどって等値面の位置を求めて描きます。
    データは 1 セル分を GPU に送り、周期的にくり返して読むので、スーパーセルにしてもデータは増えず、
    三角形の枚数の上限もありません。格子は間引かずにそのまま使います。レベルを変えるのは一瞬です。
    速くするために、(1) 面がありえない 4×4×4 格子のブロックは飛ばす、(2) 半格子ごとに調べて、
    面に入ったら二分法で位置を決める、の 2 つの工夫をしています。値の補間は三角形の方法と同じ 3 重線形補間です。
    断面（セル・スーパーセルの境界、軌道分解の球の境界）も、画面の点ごとに値から色を付けます。
  ・三角形（以前の方法）: OpenGL 3.3 が使えない PC や、レイキャスティングが使えない GPU では自動でこちらになります。
    スーパーセルは、1 セル分の三角形をずらして何回も描くインスタンス描画にしたので、メモリはセルの数によらず、
    上限は全体で 1 億枚です（OpenGL を使わない簡易描画では 400 万枚）。

断面（VESTA の Sections、v2.5.0）
  ・等値面で囲まれた部分を描画範囲（セル・スーパーセル）の境界で切った切り口を、値に応じた色で塗ります。
    VESTA の Sections と同じ考え方で、飽和レベル（最小〜最大）の間の位置で色を決めます（範囲の外は端の色）。
    色: B-G-R（最小で青、中間で緑、最大で赤）/ R-G-B / グレースケール / 等値面と同じ色。
    飽和レベルの既定は「自動」（最小 = 等値面のレベル、最大 = データの最大値）。値を入れて「反映」で固定。
  ・負の等値面がある場合（差分電荷など）、負の側の切り口は |値| で色を決めます。
  ・「等値面の断面を表示」のチェックで、表示・非表示を切り替えます。
制限 : 2D の任意の面での断面（Slice）はありません。


WAVECAR から軌道分解（② の欄）
  選んだバンドの電荷密度を、原子のまわりで s, p, d, f 成分に分けて表示します。
  例: 「フラットバンド（241, 242 番）の、A1 の d 成分だけ」
  1) 「計算フォルダを開く…」で、WAVECAR・POSCAR（または CONTCAR）・EIGENVAL のあるフォルダの WAVECAR
     （フォルダ内のどのファイルでも可）を選ぶ。そのファイルのあるフォルダを開きます。
     フォルダをこのタブにドラッグ＆ドロップしても同じです。E_F は DOSCAR → OUTCAR → WAVECAR の順に探します。
     E_F を横切るバンドの番号が表示されます。
  2) バンドを指定する: バンド番号（1 始まり。INCAR の IBAND と同じ。例 241 242 / 241-244）
     または E − E_F の範囲 [eV]（各 k点でその範囲に入る状態だけ。LPARD の NBMOD = -3 と同じ考え方）。
     「バンド番号 かつ E − E_F の範囲」（v2.5.1）: 指定したバンドのうち、各 k点でその範囲に入る状態だけ
     （例: バンド 149 150 で E_F ± 0.5 eV の状態だけ）。使った状態の数（全体のうち何個か）も表示します。
  3) 「計算」を押す。裏で計算するので、その間もほかの操作ができます（「中止」で止まります）。
  4) 計算が終わると、軌道（s p d f と各成分）・表示する元素のチェックボックスが出ます。
     チェックした組み合わせの電荷密度を、上の等値面で表示します。切り替えは計算し直さずにすぐ反映されます。
     「軌道の設定:」で「全元素」を選ぶと全元素に同じ軌道、元素（A, B, …）を選ぶとその元素だけの軌道を
     設定します（例: A は dxy、B は px）。「全元素」で選び直すと、全元素が同じ設定に戻ります。
     選んだものの球の中の電子数を、元素ごとに表示します。
     元素ごとに表示する軌道は、フォルダの POTCAR の価電子配置（VRHFIN）から決めます。s, p は常に、
     d, f は価電子配置に書かれているときだけ表示します（例: s2p4 の元素は s, p、d9 s1 の元素は s, p, d、
     5p6s5d の元素（_pv 版）は s, p, d）。表示しない軌道の成分は
     電荷密度に含めません。POTCAR がないフォルダでは、どの元素も s〜f を表示します。
  5) 「CHGCAR 形式で保存…」で、表示している組み合わせを保存できます（VESTA でも開けます）。
  成分ごとの表示（v2.4.0）
  ・軌道の欄で、p は py, pz, px、d は dxy, dyz, dz², dxz, dx²−y²、f は 7 成分に分けて選べます
    （順と定義は PROCAR・vasprun.xml の部分 DOS と同じ。x, y, z は POSCAR の直交座標の軸）。
    s / p / d / f のチェックは、その成分を全部選ぶ・外すボタンを兼ねます。
  ・複数の成分を選んだときは、選んだ軌道の組だけで作った電荷（選んだ成分の空間への射影。
    例 {dxz, dyz} なら dxz と dyz の組み合わせの成分も含む）を表示します。全成分を選ぶと p や d と同じです。
  ・成分ごとの球の中の電子数（全原子）を、計算結果の欄に表示します。
  ・既約 k点の WAVECAR でも、対称操作を「軌道の回転と原子の入れ替え」として密度行列にかけるので、
    全 k点で計算した場合と同じ結果になります（電荷密度を格子の上で平均すると px と py が混ざって誤る）。
  ・成分ごとの電子数の和は、l の電子数とわずかに（0.01 % 程度）違うことがあります。成分どうしの組み合わせの
    項は球全体で積分すると 0 になりますが、格子点での和では完全には 0 にならないためです。
  ・v2.3.x 以前の計算結果（キャッシュ・ライブラリ）は成分に分けられません。もう一度「計算」を押してください。
  球の境界の表示（v2.5.0）
  ・等値面が原子の球の境界に当たるところは、以前は格子に沿った段々（ギザギザ）になっていました。
    v2.5.0 では、球の外側の薄い殻（格子の対角線の 1.5 倍）まで展開を延ばした値で等値面を作り、球の境界で
    切り取ったうえで、球の表面の切り口を（密度行列から直接計算した値の）色付きの断面として描きます。
    セルの面での切り口と同じ色の付け方です。
  ・表示する値・電子数・保存する CHGCAR は、これまでどおり球の中だけの値です（殻の値は形を描くためだけに使う）。
  ・v2.4.0 以前の結果では、殻の値の計算に必要なデータが足りないので、もう一度「計算」を押してください
    （同じ条件でも計算し直されます）。
  計算を速くする仕組み（v2.2.0）
  ・k点の間引き: 「k点の間引き」で 2 倍・4 倍などを選ぶと、KPOINTS のメッシュを粗くした k点だけで計算します
    （例 12×12×12 → 6×6×6。k点の数がおよそ 1/8 になり、その分速くなります）。粗いメッシュの近似なので、
    間引きなしと間引きありの両方を計算すると、球の中の電子数の差（%）が表示されます。差が小さければ
    間引いた結果で十分です。KPOINTS が自動メッシュ（Gamma / Monkhorst-Pack）のときだけ選べます。
  ・同じ条件の計算結果はキャッシュに保存し、次からは計算せずにすぐ表示します
    （フォルダ・バンド・球の比・間引きが同じとき。ファイルが変わると計算し直します）。
  ・計算はコア数に合わせて k点ごとに並列で行い、計算中は残り時間の目安を表示します。
  ・球ベッセル関数は細かい表から読み取り、波動関数の展開は単精度で計算します（k点の和は倍精度）。
    正確な式・倍精度で計算した結果との差は、格子点ごとの最大値に対して 1×10⁻⁷ 程度、
    電子数で 2×10⁻⁷ 程度（相対）です。
  ・WAVECAR を外付け SSD などから読むときは、読み込みの速さで時間が決まることがあります。
  ・フォルダを開いたときの WAVECAR の確認（k点ごとの情報の読み込み）と CHGCAR の読み込みは、裏で行います
    （v2.3.1）。その間も画面は止まらず、メッセージ欄に進み具合（k点の数）と経過時間が出ます。
    確認が終わると、各段階（WAVECAR / POSCAR・EIGENVAL / E_F / 間引きの候補）にかかった時間を表示します。
  計算の方法
  ・各原子を中心とした球の中で、波動関数を実球面調和関数（PROCAR と同じ s, py, pz, px, dxy, …）で
    展開し、成分 l ごとの |ψ_l|² を k点の重みで足します。展開は平面波の展開式（球ベッセル関数）で
    係数から直接計算するので、補間の誤差はありません。
  ・既約 k点だけの WAVECAR でも正しくなるように、最後に結晶の対称操作で平均します（原子 a のまわりの
    電荷は等価な原子のまわりに移ります）。ISYM = 0 などで全 k点を計算した WAVECAR でもそのまま使えます。
  ・電子数は、スピンなしの計算では 1 バンドあたり 2（スピン分極では両スピンの和、SOC では 1）として数えます。
  ・球の半径 = 最も近い原子までの距離 × 比（既定 0.5。0.5 以下なら隣の球と重なりません）。
  制限
  ・球の外（原子と原子の間）の電荷は、どの軌道にも属さないので含みません。
  ・WAVECAR には原子核の近くの PAW の補正が入っていないので、原子核のすぐ近くの形は正確ではありません
    （VASP の PARCHG と同じ）。s/p/d の量は球の大きさで少し変わります。
  ・vasp_std / vasp_gam / vasp_ncl（SOC）の WAVECAR に対応。スピン分極（ISPIN = 2）は両スピンの和です。
  ・計算結果の値の単位は e/Å³。等値面の既定のレベルは、球の中の値だけから VESTA と同じ式で決めます。

3. DOS / BAND タブ
----------------------------------------------------------------------
読むファイル : vasprun.xml（BAND 計算と DOS 計算を別々に読み込めます）
               BAND 計算のフォルダに KPOINTS があれば、高対称点の名前を読みます。
計算側の設定 : LORBIT = 11（PDOS / PBAND を出すとき）

・表示: 「BAND + DOS」（左右に並べ、縦軸を共有）/「BAND」/「DOS」
・チェックボックス「PBAND」: 元素ごとの寄与を丸の大きさで重ねて表示（fat band）
・チェックボックス「PDOS」 : 元素ごとの状態密度。「軌道別」で s, p, d, f に分けます
・元素のチェックボックスで、表示する元素を選びます（PBAND・PDOS 共通）
・縦軸（DOS だけの表示では横軸）は E − E_F [eV] です。
・エネルギーの原点 E_F は、BAND と DOS で別々に持ちます（互いに独立）。
    BAND の E_F : BAND 計算の vasprun.xml に書かれている値が初期値
    DOS の E_F  : DOS 計算の vasprun.xml に書かれている値が初期値
  どちらも入力欄で変更できます（Enter か「再描画」）。「E_F を読み直す」で初期値に戻します。
  「BAND: VBM を 0 にする」は、占有数から価電子帯上端を求めて BAND の原点にします（DOS は変わりません）。
  「BAND に DOS の E_F を使う」は、DOS の欄の値を BAND の欄にコピーします。
  ※ line-mode の BAND 計算の E_F は、対称線上の k点だけから決めた値です。SCF・DOS 計算
    （k点メッシュ）の E_F にそろえたいときは、このボタンを使ってください。
・読み込みを速くするため、最初は固有値と全 DOS だけを読みます。PBAND / PDOS 用のデータは、
  チェックを入れたときに 1 度だけ読みます（大きなファイルではここで少し待ちます）。
・表示範囲、DOS の上限、PBAND の丸の大きさを入力欄で変更できます（Enter か「再描画」）。
・画像の保存・拡大・移動は、グラフ下のツールバー（フロッピーのアイコンで保存、300 dpi）。

対応している BAND 計算の k点の与え方
  ・line-mode（VASP Input Generator の BAND）… 区間の境目と名前を KPOINTS から読む
  ・明示的な k点リスト（"x y z 重み ラベル"）… ラベルの位置に目盛り
  ・重み 0 の k点を足した計算（ハイブリッド汎関数など）… 重み 0 の点だけを表示

制限 : 非磁性が前提です（ISPIN = 2 では BAND は最初のスピン、DOS は 2 スピンの和）。
       SOC 計算の射影は全体（最初の成分）だけを使います。

桁あふれについて
  VASP は、決められた桁数に収まらない数値を vasprun.xml に「**********」と書くことがあります。
  このアプリはその値を欠損として読み込み、個数を下のメッセージ欄に表示します。
  欠損のあるエネルギーでは、DOS / PDOS の線がその点だけ途切れます。


4. フェルミ面タブ
----------------------------------------------------------------------
読み込みを速くするため、フォルダを開いた時点では PROCAR を読みません（色は |v_F|）。
「元素の寄与」を選ぶか元素にチェックを入れたときに、PROCAR を 1 度だけ読みます。
どの k点でもエネルギーが同じバンド（SOC + 反転対称の 2 重縮退など）は、面を 1 枚にまとめて描きます。

読むファイル（「フォルダを開く…」でフォルダ内の EIGENVAL などを 1 つ選ぶと、そのフォルダを読みます）: VASPKIT 263 / 264 と同じ入力です。
  POSCAR（なければ CONTCAR）, KPOINTS, EIGENVAL, DOSCAR（E_F。なければ OUTCAR）
  PROCAR（元素ごとの寄与を見るとき。LORBIT = 11）
KPOINTS : VASPKIT 261、または VASP Input Generator の「フェルミ面 (FERMI)」で作ったもの
          （1 行目にメッシュが書かれている）。Γ中心の自動メッシュでも読めます。

変換の仕様（VASPKIT と同じ）
  ・既約 k点を、結晶の対称操作と時間反転で Γ中心メッシュ全体に展開
  ・エネルギーは E − E_F（E_F は DOSCAR の値）
  ・描画領域の上に b1, b2, b3, 斜め, 全体表示, 初期位置, .frmsf を保存…, 画像を保存… のボタンがあります。
  ・「.frmsf を保存…」で書き出すファイルは VASPKIT 263 と同じ書式
    （1 行目メッシュ、2 行目 1、3 行目バンド数、逆格子ベクトル（2π 込み）、バンド → k1 → k2 → k3 の順）。
    元素にチェックを入れていれば、その重みの和を色データとして追加します
    （VASPKIT 264 の FERMISURFACE_tot.frmsf に相当）。FermiSurfer でそのまま開けます。
  ・「frmsf には E_F を横切るバンドだけ書く」は VASPKIT の REDUCE_FERMISURFACE_FILE = .TRUE. に相当。

表示の仕様（FermiSurfer と同じ）
  ・四面体法（FermiSurfer と同じ分割）で等エネルギー面を作る
  ・第一ブリルアンゾーン（Bragg 面で切り出し）/ 逆格子の単位胞
  ・色: 「元素の寄与」「フェルミ速度 |v_F|」「バンド番号」。カラースケールは BGR（青→水→緑→黄→赤）、
    範囲は自動（最小–最大）または手入力
  ・E_F からのシフト（FermiSurfer の Shift Fermi energy）。半導体でドープ後の等エネルギー面を見るとき
  ・バンドごとの表示・非表示、ブリルアンゾーンの線、カラーバー、背景色（黒が FermiSurfer の既定）

補間（面のギザギザを減らす）
  面のギザギザは画面のアンチエイリアスの問題ではなく（4x MSAA は常に有効）、
  k点メッシュの粗さが原因です。四面体法は k点の間を直線でつなぐので、メッシュが粗いと
  面が折れ線になり、特にバンドが交差する所ではのこぎり状の穴になります
  （VASP のバンド番号はエネルギー順なので、交差する所で E_n(k) が折れ曲がるため）。
  「補間」の倍率を上げると、k点メッシュを各方向その倍率だけ細かくしてから面を作ります。
    ・補間は FermiSurfer の Interpolation と同じ 3 次補間（格子点上の値は変わりません）
    ・補間の前に、傾きが連続するようにバンドを交差をまたいでつなぎ直します（このアプリ独自）。
      元素ごとの重みも同じつなぎ方で補間します
    ・読み込み時の初期値は、メッシュの最も粗い方向が 48 点以上になる倍率（最大 6）。1 で補間なし
  補間は見た目を滑らかにするもので、計算していない k点の情報が増えるわけではありません。
  交差する線に沿って細いすき間が残る場合や、細かい構造を議論する場合は、k点メッシュを
  細かくして計算し直してください（VASP Input Generator の「フェルミ面」で k点密度「高」）。
  frmsf の保存は補間前のデータ（VASPKIT と同じ）です。

元素ごとの寄与
  「元素・原子の寄与」を選び、見たい元素にチェックを入れます。色の値はチェックした元素の
  PROCAR の重み（tot 列）の和です。1 つだけチェックすればその元素だけの寄与になります。

軌道ごとの寄与（s, py, pz, px, dxy, dyz, dz2, dxz, dx2-y2 …）
  元素・原子のチェックの下に、PROCAR の列（軌道）のチェックボックスが出ます。最初は全部オンです。
  色は「チェックした元素・原子」×「チェックした軌道」の重みの和です。
  ・「全部」「s だけ」「p だけ」「d だけ」のボタンでまとめて切り替えられます。
  ・PROCAR はフォルダを開いた直後から裏で読み込みます（読み込み中も操作できます）。
  ・軌道の向き（x, y, z）は VASP と同じで、計算セルのデカルト座標です。
  ・既約 k点からメッシュ全体に展開するとき、対称操作による軌道の入れ替わり（例: 4 回回転で px ↔ py）も
    考慮します。VASPKIT 264 はこれを考慮しないので、px などのファイルは一致しません。
  ・【注意】が出たとき: 選んだ軌道の組が、対称操作で他の軌道と混ざる場合です（例: 立方晶での dz2 だけ、
    六方晶での px だけ）。混ざり方を決める干渉項が PROCAR にないので、表示は近似になります。
    p 全体・d 全体、立方晶の dz2 + dx2-y2 や dxy + dyz + dxz のように回転で閉じた組を選ぶと正確です。
    1 個の軌道を正確に見たいときは、ISYM = -1 で全 k点を計算してください。
  ・frmsf の保存名は FERMISURFACE_A1_dxy.frmsf のようになります。

frmsf ファイルを直接開く
  「frmsf を開く…」またはウィンドウへのドラッグ＆ドロップで、VASPKIT やこのアプリで作った .frmsf を
  そのまま表示できます。
  ・エネルギーは E − E_F で書かれているので、E_F = 0 として表示します。シフトは使えます。
  ・ファイルに色のデータがあれば「frmsf に書かれている色のデータ」で表示します。しきい値も使えます。
  ・frmsf には構造と原子・軌道ごとの重みが入っていないので、元素・原子・軌道の切り替えはできません。
  ・対応するのは 2 行目が 1（Γ を含むメッシュ）のファイルだけです。

寄与の小さい面を隠す（しきい値）
  「寄与がしきい値より小さい面を隠す」にチェックを入れると、選んだ元素・原子の寄与（重みの和）が
  しきい値より小さい部分を描きません。しきい値を入力して Enter でも有効になります。
  ・判定は三角形ごと（3 頂点の平均）なので、隠れる境目は三角形の大きさ程度ギザギザします。
    補間の倍率を上げると細かくなります。
  ・「元素・原子の寄与」（元素・原子を 1 つ以上選んでいるとき）と「frmsf の色のデータ」の表示で効きます。
  ・隠した枚数は下のメッセージ欄に出ます。frmsf の保存内容には影響しません。

何も選ばないとき
  「元素・原子の寄与」の表示で、元素・原子のチェックをすべて外す（または軌道のチェックをすべて外す）と、
  フェルミ面を描きません（ブリルアンゾーンの線だけ表示）。|v_F| やバンド番号の表示では面を描きます。
  自動でチェックが入ることはありません。

原子ごとの寄与（同じ元素の原子を 1 個ずつ見る。例: A1, A2, …, A6）
  「原子ごとに分ける元素」でその元素を選ぶと、原子 1 個ずつのチェックボックスが出ます。
  チェックした原子の重みの和が色になります（他の元素のチェックと組み合わせることもできます）。
  原子の番号は POSCAR の順で、電荷密度タブのラベル、VASPKIT の ATOM_LABEL と同じです。

  仕組み: フェルミ面は、対称性で減らした既約 k点の結果をメッシュ全体に展開して描いています。
  対称操作 {R|t} で k点を移すと、原子も等価な別の原子 p(a) に移るので、
      展開先の k点での原子 p(a) の重み = 既約 k点での原子 a の重み
  となるよう、原子の移り先を追跡して重みを入れ替えています（時間反転 k → −k は原子を動かしません）。
  元素全体の和はこの入れ替えで変わらないので、元素単位の表示は今までと同じです。

  VASPKIT 264 との違い: VASPKIT は既約 k点の重みをそのままコピーするので、等価な原子が
  ほかにある原子を 1 個だけ選ぶと正しい分布になりません（等価な原子を全部選べば正しい）。
  このアプリで原子を 1 個ずつ選んで保存した frmsf は、VASPKIT 264 とは一致しません。

  見え方について
  ・反転で移り合う 2 個の原子は、同じ分布になります（非磁性では k と −k の重みが等しいため）。
    例: Pm-3n の 6c サイトにある同じ元素の原子 6 個は、鎖の向き (x, y, z) ごとの 2 個ずつ 3 組に分かれ、
    組の中は同じ、組どうしは互いに回転した分布になります。
  ・エネルギーが完全に縮退したバンド（SOC + 反転対称の 2 重縮退など）では、縮退した組の中での
    原子ごとの重みの分け方に任意性があるので、縮退した組の平均を表示します。
  ・分ける元素を変えると、面を作り直します（補間する重みの組が変わるため）。

FermiSurfer と違う点 : 投影は正射影（FermiSurfer の既定は透視投影）、光源は結晶構造表示と同じ設定。
未対応 : 断面（Section）、ノード線、ステレオグラム、軌道別（s, p, d）の寄与。


5. 輸送特性タブ
----------------------------------------------------------------------
読むファイル : vaspout.h5（ELPH_MODE = TRANSPORT の計算。VASP Input Generator の
               「輸送 CRTA」「輸送 SERTA/MRTA」）

・ゼーベック係数 S [μV/K]、電気伝導率 σ [S/m]、電子熱伝導率 κe [W/(m K)] を並べて表示。
・平均は常に表示。チェックボックス「異方性（a, b, c 軸方向）を表示」で各軸方向を重ねます。
  a, b, c それぞれのチェックで個別にオン・オフできます。
    平均        : (T_xx + T_yy + T_zz) / 3
    軸方向の値  : 軸方向の単位ベクトル n に対して n·T·n（T はデカルト座標のテンソル）
  単斜晶のように軸が直交しない場合も、a, b, c 軸そのものの方向の値です。
・データ（散乱近似・キャリア密度の組み合わせ = アキュムレータ）をチェックで選びます。
・横軸: 温度、または キャリア密度 / 化学ポテンシャル（温度を選ぶ）。
・「表示中のデータを CSV で保存…」。画像はグラフ下のツールバーから。

注意 : このタブは、実際の VASP の出力ファイルではまだ確認していません
       （py4vasp の定義どおりに作ったテスト用ファイルで、py4vasp と同じ値を読めることを確認）。
       ゼーベック係数は py4vasp にならい V/K として読み、μV/K に換算しています。
       値の大きさから μV/K で書かれていると判断した場合は換算しません（読み込み時に表示）。
       OUTCAR の輸送の表（μV/K）と一度見比べてください。


5-2. 結晶構造タブ（v2.3.0）
----------------------------------------------------------------------
VASP Input Generator の「結晶構造を表示」と同じ表示です。
読み込み : 「POSCAR / CONTCAR を開く…」、POSCAR / CONTCAR のドラッグ＆ドロップ。
           電荷密度（CHGCAR・WAVECAR のフォルダ）・DOS / BAND（vasprun.xml）・フェルミ面（計算フォルダ）を
           開くと、そのデータの構造が自動でこのタブに入ります（描くのはタブを開いたとき）。
           フォルダを開いた場合は CONTCAR（中身があれば）→ POSCAR の順に使います。
           vasprun.xml からは最終構造を使います。
表示     : 組成・空間群・格子定数・体積。スーパーセル、視点ボタン（描画領域の上に a, b, c, a*, b*, c*, 斜め、
           全体表示、初期位置、画像を保存）、結合、結合相手を境界外にも表示（VESTA 既定）、境界上の原子、
           範囲外への結合を半分だけ表示、単位胞、結晶軸、球の大きさ・結合の半径・ラベルの文字サイズ、
           元素ごとのラベル、元素対ごとの結合の表（VESTA の結合距離表が既定値）、画像の保存（PNG）。
           異常に近い原子対（共有結合半径の和の 0.5 倍未満）があると赤字で警告します。
           色・原子半径は VESTA の elements.ini の既定値です。

5-3. ブリルアンゾーンタブ（v2.3.0）
----------------------------------------------------------------------
VASP Input Generator の「ブリルアンゾーンを表示」と同じ表示です。
・左: 元の構造（入力 POSCAR）の BZ、右: seekpath の標準化プリミティブセルの BZ。
  推奨パス（HPKOT）と高対称点を赤で表示し、各図の下にパスの文字列を表示します。
・左右の回転を連動、初期位置に戻す、表示する軸（逆格子 b₁b₂b₃ / 実空間 a,b,c / 直交座標 x,y,z）、
  画像を保存（左右を並べ、見出し帯付きの PNG）。
・構造の読み込みは結晶構造タブと共通です（片方で開くと、もう片方にも入ります）。
・seekpath が入っていない環境では、元の構造の BZ だけを表示します（高対称点なし）。
・結晶構造・ブリルアンゾーンタブも、表示の状態の復元・最近開いたもの・ライブラリへの保存に対応しています。


6. 描画方式
----------------------------------------------------------------------
3D 表示は OpenGL 3.3（PyOpenGL + pyopengltk、4x MSAA）。使えない環境では自動的に
簡易描画（Pillow）に切り替わります（回転は遅くなります）。
環境変数 VASP_VIEWER_NO_GL=1 を設定して起動すると、最初から簡易描画になります。


7. exe の作り方
----------------------------------------------------------------------
Windows + Python 3.14 で build_exe.bat を実行します（vasp_viewer.py と同じフォルダに置く）。
依存: numpy, spglib, seekpath, pillow, matplotlib, h5py, PyOpenGL, pyopengltk, tkinterdnd2, pyinstaller
（v2.3.0 から seekpath を使います（ブリルアンゾーンタブの推奨パス）。build_exe.bat に追加済みなので、
  以前に exe を作ったフォルダでも、build_exe.bat をもう一度実行すれば入ります）
ソースから直接動かす場合:  python vasp_viewer.py


8. 設定値の変更
----------------------------------------------------------------------
vasp_viewer.py の「設定値」の部分を書き換えます。
  ISO_SIGMA_N, ISO_OPACITY, CHG_AUTO_MAXGRID, CHG_MAX_TRIANGLES … 等値面
  FS_INTERP_TARGET, FS_INTERP_MAX              … フェルミ面の補間
  LABEL_SIZE                                   … 原子ラベルの文字サイズの初期値
  ENERGY_WINDOW, FATBAND_SCALE, PLOT_COLORS    … DOS / BAND
  BALL_SCALE, BOND_RADIUS                      … 原子・結合（VASP Input Generator と同じ値）


9. 確認した内容
----------------------------------------------------------------------
・frmsf 変換: VASPKIT 1.5.1 の task 263 / 264 の出力と、全バイト一致
  （VASPKIT 付属の計算例。264 は重みを人工的に作った PROCAR で確認）
・k点の展開: fcc, bcc, 六方, 正方, 単斜 (C2/m) で、対称な関数を正しく再現
・vasprun.xml / CHGCAR / PROCAR / EIGENVAL: pymatgen の読み込み結果と一致
  （pymatgen・sumo のテスト用の実際の VASP 出力。SOC の計算を含む）
・等値面: 球の面積、ブリルアンゾーンへの折り返しで面積が保存されることを確認
・軌道ごとの寄与: 立方晶・正方晶（格子を 45° 回したものを含む）・六方晶・単斜晶の模型で、既約 k点から
  展開した値が直接計算した値と一致することを確認（回転で閉じた軌道の組の場合）。
  正方晶の模型で、s, dz2, dxy, dx2-y2 の frmsf は VASPKIT 264 と全バイト一致。px は VASPKIT 264 と
  一致せず、直接計算した値と合うのはこのアプリの方。
・原子ごとの寄与: 立方晶 Pm-3n（6c に同じ元素の原子 6 個）、正方晶 P4/mmm・P4_2/mnm、六方晶、単斜晶 C2/m の
  模型で、対称性を満たす原子ごとの関数を既約 k点から展開し、直接計算した値と一致することを確認。
  同じ模型で VASPKIT 264 は原子 1 個の重みを誤って展開することも確認（元素の和は一致）
・補間: 交差する 2 枚のシートの模型（30×30×15 メッシュ、4 倍）で、E_F 付近の誤差の rms が
  補間なし 0.024 eV → バンドごとの補間 0.015 eV → 交差を考慮した補間 0.0015 eV
・速度（v1.2.0、Linux の試験環境での実測）:
    vasprun.xml 197 MB（SOC, 65 原子）の DOS 読み込み   4.2 秒 → 0.5 秒（PDOS は後から 1.2 秒）
    PROCAR 2.3 GB（18 原子・非共線・2452 k点・160 バンドの合成データ）   9.3 秒 → 1.1 秒
    ブリルアンゾーンへの折り返し（三角形 200 万枚）   29 秒 → 約 2.5 秒
    上の合成データでフォルダを開いてから表示まで   約 5.5 秒（補間 ×4、三角形 100 万枚。うち約 1 秒は
    試験環境のソフトウェア描画）
・桁あふれ: 実際の vasprun.xml の数値を人工的に '****' に書き換えたファイルで、
  残りの値がすべて元と一致することを確認（利用者の実ファイルでは未確認）
・未確認: Windows での exe 化と実機の GPU での表示、実際の vaspout.h5（輸送）
